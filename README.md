# Intelligent Abnormal Electricity Usage Analysis

## Project Overview
This project analyzes residential electricity consumption and identifies abnormal electricity usage patterns using Tableau.

## Objectives
- Analyze actual and expected electricity consumption.
- Identify abnormal electricity usage.
- Compare energy consumption across regions.
- Understand household electricity usage patterns.

## Tools Used
- Tableau
- Microsoft Excel

## Dataset
The dataset contains residential electricity consumption information from Kerala, including meter details, actual energy, expected energy, usage deviation, temperature, humidity, and dwelling type.

## Dashboards

### Dashboard 1 – Electricity Consumption Overview
Analyzes overall electricity consumption, expected vs actual energy, and household usage patterns.

### Dashboard 2 – Abnormal Usage & Intelligence Analysis
Identifies abnormal electricity usage based on region, dwelling type, usage deviation, and environmental factors.

## Key Features
- KPI Cards
- Interactive Filters
- Electricity Consumption Analysis
- Abnormal Usage Detection
- Data Visualization

## Future Improvements
- Integrate real-time electricity consumption data.
- Apply machine learning for abnormal usage prediction.
